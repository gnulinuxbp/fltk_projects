# FLinux + Xorg — Modified Applications

## English

This repository contains modified applications forked from the official Tiny Core Linux applications. These modifications are intended for use with **[FLinux + Xorg - Testing (Unofficial)](https://sourceforge.net/projects/flinux-xorg-testing-no-oficial/)**.

This is an unofficial project and is not affiliated with or endorsed by the Tiny Core Linux developers.

## Español

Este repositorio contiene aplicaciones modificadas a partir de las aplicaciones oficiales de Tiny Core Linux. Estas modificaciones están destinadas a utilizarse en **[FLinux + Xorg - Testing (No oficial)](https://sourceforge.net/projects/flinux-xorg-testing-no-oficial/)**.

Este es un proyecto no oficial y no está afiliado ni cuenta con el respaldo de los desarrolladores de Tiny Core Linux.
